# discord-boost-checker

I got tired of clicking through Discord's UI to figure out which servers I was still boosting. This fetches my guild memberships and shows active boost status.

## install

pip install -r requirements.txt

## usage

python discord_boost_checker.py --token <your_discord_token>

Grab your token from the browser devtools (Application > Local Storage > token) or a Discord client mod. It needs the `guilds` scope.
